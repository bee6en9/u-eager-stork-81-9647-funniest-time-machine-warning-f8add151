## The label

> WARNING: Do not step on a butterfly in 65,000,000 BC. It is your boss now.

One line, 74 characters. A genuine-looking safety warning whose punch lands
in the last five words: the butterfly effect made concrete (a date, not a
lecture), escalating to the absurd — the butterfly you stepped on is now
your boss.

## How it works

`main.ts` (Node, no external dependencies) writes the single deterministic
label to `/output/entry.txt`:

```sh
node main.ts
```

Every run writes byte-identical output.
